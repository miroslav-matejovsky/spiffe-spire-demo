SPIFFE/SPIRE Documentation

Comprehensive guide for deploying and operating SPIFFE/SPIRE for zero-trust workload identity across traditional and hybrid infrastructure, with agents on Windows and Linux VMs or physical machines connecting back to a centralized SPIRE server.

Guide Focus

Use this documentation as both a learning path and an operator reference. It maps core SPIFFE ideas to a hub-and-spoke SPIRE deployment model where one agent runs on each machine with limited access and connects back to a centralized server.

What you'll learn

  • How SPIFFE provides workload identity for services running on VMs and physical machines
  • How SPIRE fits into a hub-and-spoke deployment with a centralized server and distributed agents
  • How to deploy SPIRE agents on restricted Windows and Linux machines
  • How to configure attestation, registration, trust bundles, and workload identity delivery when connectivity is limited
  • How to evaluate production readiness, conservative infrastructure hardening, and scaling concerns

About this guide

This guide maps directly to the seven hands-on scenarios in this repository. Those scenarios use Linux containers for learning convenience, but the guide targets real deployments with centralized SPIRE servers and agents running on Windows or Linux VMs and physical machines.

Content and navigation assume SPIRE v1.15.0 so the examples and terminology stay aligned with current upstream documentation and runtime behavior.

Best way to use guide

Read concept pages first, then run matching scenarios in order. That pattern helps connect identity theory with commands, configuration, and runtime behavior.
